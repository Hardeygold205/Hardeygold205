## 🚀 About Me

I am a **Full-Stack Software Engineer** specializing in web and mobile application development, with experience building and deploying production-ready applications using **JavaScript, TypeScript, PHP, and modern frameworks including React, Next.js, React Native, Node.js (Express), and Laravel**. I also have hands-on experience with **WordPress CMS development, custom content management systems, and Linux server administration**, including application deployment, **CI/CD pipelines, Nginx, Apache, PM2, and GitHub Actions**. I have a strong foundation in software architecture, REST API integration, database design, performance optimization, and building scalable, maintainable systems. My background in Physics has strengthened my analytical thinking and structured approach to solving complex engineering problems. I am passionate about building reliable, user-focused software that performs well in production.


## 💼 What I Do

- Build responsive web applications with React, Next.js, and TypeScript
- Develop backend systems and admin platforms using Laravel, Livewire, and Node.js
- Create and customize WordPress websites and CMS solutions
- Convert Figma designs into production-ready interfaces
- Integrate REST APIs, third-party services, and Web3/blockchain tooling
- Deploy and manage applications on Linux servers (VPS/cPanel)
- Configure Nginx, Apache, PM2, and GitHub Actions
- Optimize application performance and scalability

I enjoy building applications that are maintainable, performant, and production-ready. Whether developing responsive user interfaces, building backend services, deploying applications to Linux servers, or managing CI/CD pipelines, I focus on creating software that is reliable and easy to scale.
